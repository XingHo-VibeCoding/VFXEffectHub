# VFXEffectHub 前端规则（frontend-guidelines）

> 用途：修改本项目的 HTML / CSS / JS 前，先读本文件，按下面规则执行。
> 来源：Day 8–11 逐步拍板确认的规则，不是凭空想象。

## 1. 页面层级（信息层级）

- 顶部三区各司其职、视觉分开：
  - **品牌区**（`site-header` / `site-header--home`）：站名 + 副标题
  - **导航区**（`.tabs`）：Unity / UE / 贴图 / 我的收藏，独立灰底条（背景 `#f6f8fa`）
  - **筛选区**（`.toolbar--home`）：搜索 + 下拉 + 按钮，圆角白卡片（`padding:16px` + 边框 `#d0d7de` + 圆角 8px）
- 状态提示用 `status__box` 居中框；成功态不显示提示框（`status--ok` 隐藏）。
- 字号走「阶梯」不「斜坡」：标题 / 正文 / 辅助 = 清晰三级，勿 11/12/13px 混用。

## 2. 颜色和字体

**颜色（写死就抄这些，别自造新灰/新蓝）：**

| 用途 | 值 |
|---|---|
| 正文文字 | `#1f2328` |
| 辅助文字（作者名/页脚/提示） | `#57606a`（对比度 ≥4.5:1，勿退回 `#8b949e`） |
| 主色 / 链接 / 焦点 | `#1f6feb` |
| 主色 hover | `#1a5dc8`，active `#174ea6` |
| 边框 | `#d0d7de`；浅分隔线 `#eaecef` |
| 浅灰背景 | `#f6f8fa`；页面背景 `#f6f7f9` |
| 成功 | `#1a7f37`（绿）；边框 `#2da44e` |
| 警告 | `#bf8700`；点亮态 `#fff8e6` + `#f0a825` |
| 错误 | `#cf222e`；错误底 `#fff8f8` |

**字体：** 正文/辅助 12px、正文 14px、卡片标题 15px、区块标题 16px、站名 24–32px。中文优先，技术名词保留英文。

## 3. 卡片与按钮

- 卡片 `.card`：封面 + 标题（2 行截断）+ 作者 + 标签 chip，瀑布流（`column-count` 桌面 3 / 平板 2 / 手机 1）。
- 标签 chip：`padding 2px 8px`、`font-size 12px`、`#57606a` + 底 `#f0f1f3`、圆角 10px。
- 按钮 `.btn` 全站唯一一套，四态齐全：
  - 默认：白底 + 边框 `#d0d7de`
  - hover：边框变蓝 `#1f6feb`
  - active：底色 `#f0f1f3`
  - focus：`:focus-visible` 蓝色外框 2px（键盘可见，鼠标不打扰）
  - disabled：置灰 + 不可点
- 状态式按钮（点赞/收藏）用 `.btn--active` 点亮态。

## 4. 移动端适配

- 断点 `@media (max-width: 560px)`：瀑布流单列、工具栏自动换行。
- 触控目标高度 ≥44px（按钮/搜索框/下拉 min-height）。
- 无横向溢出：`document.documentElement.scrollWidth > clientWidth` 必须为 `false`。
- `.tabs` 可横向滑动但隐藏滚动条（`scrollbar-width:none`）。
- 吸顶：`.tabs` `position:sticky; top:0`，`.toolbar--home` `top:56px`（全端）。

## 5. 修改前检查

- 只动要动的文件；不改数据、接口、其他卡片逻辑。
- 查类名是否已存在（避免重复定义覆盖旧规则——Day 9 `.btn` 教训）。
- 保持「必须不变的功能」：四状态、tab 切换、搜索筛选、详情跳转。
- 数据安全：渲染任何外部文本必须 `escapeHtml` / `escapeAttr`（防 XSS）。

## 6. 修改后验证

- 必须 `http://localhost:8000/` 起本地服务器验证，禁 `file://` 双击（fetch 会假成功）。
- 每次改完 `Ctrl+Shift+R` 强刷（清缓存）。
- 用 `node --check js/xxx.js` 校验 JS 语法。
- 交验截图须含地址栏。

## 7. 筛选交互规范（列表筛选三态）

筛选入口：关键词搜索 + 平台 tab（Unity/UE/贴图）+ 游戏名下拉 + 特效类型下拉。

- **匹配（有结果）**：显示对应卡片瀑布流。
- **无匹配（空状态）**：显示居中框，文案「没有符合条件的作品」+ 说明「试着清除搜索或筛选条件」+ 「清除筛选」按钮。
- **清空（恢复）**：点「清除筛选」或「🔄 刷新」后，回到初始列表；「刷新」只重渲染内容、**不清空**当前搜索/筛选。
- 二次筛选（游戏名 + 特效类型）与搜索是 **AND 叠加**；搜索是标题 OR 标签命中。
