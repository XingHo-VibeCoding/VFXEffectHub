## 用户纠正过的错误（重要，避免重复）
1. **按引擎分类不是最主要维度 → 进而改为三个维度完全平级 → 进而改为「标签完全自定义，不预设字典」**：用户最终拍板：不预设「特效类型/关联游戏/引擎」这种固定维度，**所有标签用户自由打**；搜索就是「在搜索框里输入任意标签关键词」找到打过这些标签的作品；筛选不是点击预设按钮。已修订。
2. **视频比静态图更适合展示特效**——我之前写过 B 站「视频为主看图不方便」，用户纠正为「**视频能更直观观察特效**」，且「**求职作品集也可以当参考**」。已修订。
3. **花瓣网是「特效师去找参考的地方」**——不是「特效师聚集地」（供给侧）。措辞已修订。
4. **画贴图是特效制作的「其中一环」**——不是核心 / 全部。完整链路包含建模 / 贴图 / 绑定 / 引擎实现 / 调参 / 渲染……，本项目只覆盖「找参考」一段。已修订。
5. **花瓣素材主要用来参考，不是下载**——已写入第 4 节「素材主要被当作视觉参考使用」。
6. **内容按「视频 / 贴图」两大素材形态分区**——顶层入口，用户进站选「找视频参考」或「找贴图参考」；详情页分形态展示（视频播放器 / 贴图大图）；手动收录时必须选素材形态 + 填三个标签。已修订。
7. **手动收录不必填标签**——最初我设计为「必须填三个标签，否则筛选不生效」，用户改为「只填来源链接即可入库；标签是可选的——想要能筛就填、不填也能找到（瀑布流/收藏夹）」。已修订。
8. **自定义收藏夹是核心机制**——用户主动提出「用户可为自己建收藏夹，按需命名」。已加入 5.1 第 7 项。
