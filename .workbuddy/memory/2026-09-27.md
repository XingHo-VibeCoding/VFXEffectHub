## 定位的问题
**问题**：主页面顶部「品牌区」与「分区 tabs」之间区分度不够，tabs 与下方「筛选工具栏」也黏在同一层白色背景里，视觉上像一整块，没有清晰的层级。

**相关文件**：
- `index.html`：结构是 header → nav.tabs → main.container（含 .toolbar--home）
- `css/style.css`：`.site-header--home`、`.tabs`、`.toolbar--home` 的样式

**可能原因**：
1. header 与 tabs 共享白色背景，中间只有一条极浅的 `border-bottom: 1px solid #eaecef`
2. tabs 与 toolbar 之间是纯空白，没有视觉边界
3. 三个区域（品牌 / 导航 / 筛选）没有各自独立的「块」感

## 修复方案（只动筛选/导航区布局和间距）
- `.site-header--home`：`padding-bottom` 从 20px 提到 24px，让品牌区与 tabs 呼吸感更强
- `.tabs`：加浅灰背景 `#f6f8fa`、顶部边框 `#eaecef`、底部边框加深到 `#d0d7de`、`padding-top` 从 0 提到 8px，使 tab 条成为独立视觉带
- `.toolbar--home`：加白色卡片面板（`padding: 16px`、`border: 1px solid #d0d7de`、`border-radius: 8px`），让筛选区从内容中凸显
- 移动端同步微调：header 底 padding 16px、tabs padding 8px 16px 0、toolbar padding 12px

## 追加修复 1（用户验证过程中发现）
**问题**：手机端下拉页面时，tab 导航栏会随页面滚走，用户希望它吸顶固定在顶部。

**相关文件**：`css/style.css` 移动端媒体查询 `.tabs`

**修复方案**：在 `@media (max-width: 560px)` 内给 `.tabs` 加 `position: sticky; top: 0; z-index: 100;`
- `top: 0`：贴在视口最顶部
- `z-index: 100`：保证卡片、工具栏滚动时从 tabs 下方经过，不被覆盖
- 只在移动端生效，桌面端保持原布局

## 追加修复 2
**问题**：用户进一步要求搜索/筛选工具栏在移动端下拉时也不要滚走，与 tabs 一起固定。

**相关文件**：`css/style.css` 移动端媒体查询 `.tabs`、`.toolbar--home`

**修复方案**：
- 给 `.tabs` 定高 `56px`，让 `.toolbar--home` 的吸顶偏移有可靠基准
- `.toolbar--home` 加 `position: sticky; top: 56px; z-index: 99;`
- 调整 `.tab` 为 `height: 48px; display: inline-flex; align-items: center; padding: 0 16px;`，确保定高后文字居中

## 追加修复 3
**问题**：用户选择 B，要求桌面端也吸顶。

**相关文件**：`css/style.css` 全局 `.tabs`、`.tab`、`.toolbar--home`

**修复方案**：
- 把 `.tabs` 的 `position: sticky`、高度、`z-index` 提到全局规则
- 把 `.toolbar--home` 的 `position: sticky`、顶部偏移、`z-index` 提到全局规则
- `.tab` 全局改为定高 48px + flex 居中，保证全宽度下吸顶位置一致
- 移动端媒体查询只保留 padding/gap 覆盖，不再重复吸顶逻辑
